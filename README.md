# ml-math

## Module 1: The Input Tensor
    Creating a function that takes in a raw data vector and scales it sothat the model can process it efficiently.

This is called __Normalization__. Normalization (or feauture scaling) is a preprocessing technique that rescales numerical input features to a standard range (typically 0 to 1 or -1 to 1) or distribution. We do this to ensure the models math wont be overwhelmed by the wildly different scales of the features. It keeps the importance of each feature balanced.
